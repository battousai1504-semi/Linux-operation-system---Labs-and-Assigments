# LOS201 – Lab 02

Student: Phan Dang Ai Truc

## Objectives

- Build and test a Linux character device driver.
- Communicate between user space and kernel space.
- Expose driver information through procfs and sysfs.
- Load the kernel module during initramfs startup.
- Create and test a JFFS2 filesystem on an MTD NAND simulator.

## Main components

- `practice/`: basic kernel-module practice.
- `driver/`: Lab 02 character device driver.
- `rootfs/`: initramfs startup and test scripts.
- `mtd/`: files used to create the JFFS2 image.
- `docs/`: progress notes and test evidence.

Generated binaries, kernel modules, logs and filesystem images are not stored in Git.
